# Week 4: Wireless Communication

## Q31: Bluetooth LED Controller Installation & Pairing
1. Power up the Arduino circuit. The HC-05 module's red LED will blink rapidly.
2. Open Bluetooth settings on your Android device and scan for devices.
3. Select **HC-05** and pair using the pin code **1234** (or **0000**).
4. Download a "Bluetooth Terminal" app from the Play Store.
5. Connect to the HC-05 inside the app and send uppercase characters (`R`, `G`, `B`, `X`, `F`) to control the hardware.
